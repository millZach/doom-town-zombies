The round stingers — the ones that used to screech

Each of these is an ElevenLabs sting layered with real pipe organ, tubular bell, gong and timpani samples, then low-passed so nothing sits above ~4 kHz. Play them a few times in a row: they should feel like dread, never like a shriek.
